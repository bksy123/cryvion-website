# CRYVION PRIVATE LIMITED website

Responsive static company website for security services, manpower supply and facility support.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation and enquiry form mailto behaviour

## Before publishing
1. Replace `YOUR-BUSINESS-EMAIL`, `YOUR-CONTACT-NUMBER`, and `YOUR-CITY, INDIA` in `index.html`.
2. In `script.js`, replace `REPLACE-WITH-YOUR-EMAIL@example.com` with the real company email.
3. Confirm the services and legal/licence statements accurately describe your company.
4. Do not publish a licence number, address, certification or claim unless verified.

## Hosting
This is a static HTML/CSS/JS website. It does not require WordPress or a database. For a commercial business site, choose a host whose terms explicitly permit commercial websites; you can keep the source code in GitHub and deploy via a suitable static host such as Cloudflare Pages.

## Contact form note
The form opens the visitor's default email app using `mailto:`. It does not store submissions or send them automatically. For a proper web-based enquiry form, connect a form service or backend.
